# mcp-agentframework-examples

This repository contains dotnet MCP examples and usage of agent framework.

# MCP-Servers

In this repo is one example of a HTTP transport MCP server.

## UserMgmtServer

 This MCP servers has 3 tools to enumerate the users, the authgroups and the user with thier assigned authgroup.

 Using the build-start-mcp-server.sh script you can build this project in a docker container and start it running on http://localhost:8080.

 using the .vscode/mcp.json you can acces the tools using copilot!
